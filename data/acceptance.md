# Native Codex acceptance

Verified with Codex CLI 0.171.0 on macOS in a temporary user profile. The installer registered the marketplace and installed the plugin. A second installation reused the marketplace, existing configuration and SQLite history.

A real Codex App Server opened a test chat using a local mock model. It discovered the eight monitor tools and read the panel HTML through MCP. The worker ran as a separate process. Local Slurm command fixtures reported an empty queue followed by a completed array member in accounting. The watch fired, the existing chat received exactly one additional turn, and the delivery reached `completed`. The test acknowledged the matching event through MCP. All jobs, prompts and chats in this test were synthetic.

The acceptance run started the worker directly. It did not exercise desktop rendering, actual scientific jobs or a production service manager. The test suite in `data/tests/` independently exercises grouped waits, busy chats, process restarts, lost replies, prompt overrides, cancellation and signed callbacks.
